# Origen del código de aplicación

## Reutilizado (vendorizado)

| Componente | Repositorio | Commit | Licencia |
|---|---|---|---|
| Backend | https://github.com/gothinkster/node-express-realworld-example-app | `30b68e1e881462b2f4164ea09ab4c4f5699c7b0b` | MIT |

Se vendoriza (sin submódulos) porque hay que modificar configuración de conexión y agregar
Dockerfile propio: con submódulos esos cambios vivirían en otro repositorio.

## Reescrito

| Componente | Motivo | Stack |
|---|---|---|
| Frontend | La implementación de referencia (2018) usa `react-scripts 1.1.1`, React 16.3 y no tiene lockfile: no compila en un Node soportado y no es reproducible | Vite 5 + React 18, SPA mínima sobre el mismo contrato de API |

Decisión registrada en `docs/05-decisiones.md` (D-18). El **dominio, el esquema y la API** siguen
siendo los de la aplicación existente (Conduit/RealWorld); lo reescrito es la capa de
presentación.

## Qué se modificó respecto del upstream

| Archivo | Cambio | Motivo |
|---|---|---|
| `backend/*` | conexión a PostgreSQL por `DATABASE_URL` (ya soportado por Prisma) | §4 |
| `backend/*` | `JWT_SECRET` obligatorio, sin fallback `'superSecret'` | hallazgo de §14 |
| `frontend/*` | reescrito completo | D-18 |

Este archivo se actualiza si se cambia el commit base del backend.
