## Por qué vendorizado y no submódulo

- El repositorio del integrador debe ser **autocontenido**: `git clone` y `docker compose up`
  sin `--recursive`.
- Necesitamos modificar la configuración de la API (URL por variable de entorno) y agregar
  Dockerfiles; con submódulos esas modificaciones viven en otro repo.
- La trazabilidad se conserva acá: commit exacto + licencia.

## Qué se modificó respecto del upstream

| Archivo | Cambio | Motivo |

| `frontend/src/*` | URL de API por `REACT_APP_BACKEND_URL` | evitar `localhost` hardcodeado (§7) |
| ambos | `Dockerfile` propio con build multi-stage | §7 |

Este archivo se actualiza si se cambia el commit base.
